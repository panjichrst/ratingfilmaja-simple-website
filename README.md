🎬 RatingFilmAja – My Movie List
A simple personal movie collection website built using HTML5, CSS3, Bootstrap, and Vanilla JavaScript.
RatingFilmAja allows users to manage their personal movie collections, explore movies by genre, view movie details, and organize their favorite films through a simple and responsive interface.

✨ Features
Movie Recommendations – Displays the highest-rated movie from each available genre.
Genre-Based Browsing – Explore movies by Action, Thriller, Horror, Drama, and Crime genres.
Create Movie – Add new movies with a title, release year, genre, description, poster, and rating.
Read Movie – View movie collections and detailed movie information.
Update Movie – Edit existing movie information, including its poster and rating.
Delete Movie – Remove movies with a confirmation prompt.
Movie Search – Search for movies by title.
Local Data Storage – Save movie collections using browser localStorage.
Responsive Design – A layout designed to work across desktop and mobile screens.
